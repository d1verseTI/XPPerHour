# XPPerHour

A World of Warcraft addon for the **Forever** client (Interface 16001). It shows a small window with your XP per hour, time to level, and how many more of your recent XP gains you need to level.

- Rates for both the whole session and the last 10 minutes
- Time to level at the current rate
- "Gains to level", based on your last 10 XP gains (kills, quests, …)

## Commands

| Command | Does |
|---|---|
| `/xph` | Show or hide the window |
| `/xph reset` | Reset the session |
| `/xph lock` | Toggle locking the window in place |

## Install

Copy the `XPPerHour` folder into `World of Warcraft\_forever_\Interface\AddOns\` and restart the game or `/reload`.
